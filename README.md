## About

I'm interested in machine learning, evolutionary computation and quantitative modelling. I particularly enjoy projects where I can design an algorithm, train or optimise it, and measure how well it performs rather than relying on a black-box API.

This profile is a record of what I've built and what I'm exploring.

## Projects

### Mario Player using Neuroevolution

Train an agent to play a classic platformer using NEAT (NeuroEvolution of Augmenting Topologies). Instead of hand-coding the controls, evolve neural-network structures and weights by selecting agents that make the most progress.

<p><strong>Stack:</strong> &nbsp; <a href="https://www.python.org/" title="Python"><img src="https://skillicons.dev/icons?i=python" width="36" height="36" alt="Python"></a> &nbsp; <a href="https://neat-python.readthedocs.io/" title="NEAT-Python"><img src="https://api.iconify.design/mdi/brain.svg?color=%23a78bfa" width="36" height="36" alt="NEAT-Python (brain symbol)"></a> &nbsp; <a href="https://docs.libretro.com/" title="NES emulator"><img src="https://api.iconify.design/mdi/controller-classic.svg?color=%23e5e7eb" width="36" height="36" alt="NES emulator (controller symbol)"></a> &nbsp; <a href="https://numpy.org/" title="NumPy"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/numpy/numpy-original.svg" width="36" height="36" alt="NumPy"></a> &nbsp; <a href="https://matplotlib.org/" title="Matplotlib"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/matplotlib/matplotlib-original.svg" width="36" height="36" alt="Matplotlib"></a></p>

### Limit Order Book Modelling


A convolutional neural network (CNN) that can learn short-term price-movement signals from sequences of bid/ask prices and volumes. Compare the CNN against simpler statistical and machine-learning baselines.

<p><strong>Stack:</strong> &nbsp; <a href="https://www.python.org/" title="Python"><img src="https://skillicons.dev/icons?i=python" width="36" height="36" alt="Python"></a> &nbsp; <a href="https://pytorch.org/" title="PyTorch"><img src="https://skillicons.dev/icons?i=pytorch" width="36" height="36" alt="PyTorch"></a> &nbsp; <a href="https://www.tensorflow.org/" title="TensorFlow"><img src="https://skillicons.dev/icons?i=tensorflow" width="36" height="36" alt="TensorFlow"></a> &nbsp; <a href="https://pola.rs/" title="Polars"><img src="https://cdn.simpleicons.org/polars/CD792C" width="36" height="36" alt="Polars"></a> &nbsp; <a href="https://scikit-learn.org/" title="scikit-learn"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/scikitlearn/scikitlearn-original.svg" width="36" height="36" alt="scikit-learn"></a></p>


What I want to publish: reproducible data processing, chronological train/test splits, ablation studies and cost-aware backtests. This is a research project, not a claim of profitable trading.

### Image Retrieval from Scratch


Build an image search engine that retrieves visually similar pictures using CNN embeddings and nearest-neighbour search. Experiment with contrastive learning and benchmark retrieval quality against a basic feature extractor.
